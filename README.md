SanMartin AI Agent es una aplicación web interactiva basada en inteligencia artificial que permite a los usuarios conversar con una versión virtual de José de San Martín mediante una interfaz estilo chat.

El agente fue diseñado para responder preguntas relacionadas con la vida, campañas militares, trayectoria y legado de San Martín, utilizando información histórica y procesamiento de lenguaje natural para generar respuestas contextualizadas desde la perspectiva del personaje.

El proyecto combina inteligencia artificial y desarrollo web para transformar contenidos históricos en una experiencia interactiva, educativa e inmersiva.

Objetivos del proyecto

* Desarrollar un agente conversacional basado en inteligencia artificial
* Crear una experiencia educativa e interactiva
* Explorar aplicaciones de IA en contenidos históricos
* Diseñar una interfaz web intuitiva y accesible

Funcionalidades

* Interacción conversacional en tiempo real
* Respuestas basadas en información histórica
* Simulación de conversación con José de San Martín
* Interfaz web dinámica e intuitiva
* Experiencia enfocada en aprendizaje e interacción

Tecnologías utilizadas

* HTML
* CSS
* JavaScript
* APIs de inteligencia artificial
* Modelos de lenguaje
* Desarrollo web responsive
